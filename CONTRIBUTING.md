# Contributing

Thanks for improving the Jenkins learning lab.

Good contributions include updated Jenkins practices, reusable pipelines, troubleshooting scenarios, security guidance, diagrams and small self-contained labs.

Before opening a PR:

1. Never commit secrets or private infrastructure details.
2. Use placeholders for credentials, registries, account IDs and endpoints.
3. Keep examples runnable or mark them as conceptual.
4. Explain why a stage or tool is needed.
5. Use current Jenkins terminology: controller and agent.
6. Update documentation when adding a major topic.

Checklist:

- [ ] No credentials or private endpoints
- [ ] Documentation updated
- [ ] Example syntax reviewed
- [ ] Security implications documented
